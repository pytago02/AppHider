# AppHider

AppHider là một tiện ích nhỏ gọn gọn trên Windows giúp bạn nhanh chóng ẩn các ứng dụng đang chạy để bảo vệ sự riêng tư.

## Tính năng chính
- **Ẩn khi Alt+Tab**: Cửa sổ biến mất hoàn toàn khỏi màn hình và danh sách Alt+Tab, thu nhu nhỏ ứng dụng vào system tray.
- **Chỉ ẩn Taskbar**: Ẩn icon ứng dụng khỏi task bar và đưa vào system tray.
- **Giao diện hiện đại**: Hỗ trợ Dark/Light mode tự động tương thích với Windows 11.
- **Portable**: Tải về chạy ngay, không cần cài đặt.

## Tải về
Bạn có thể tải trực tiếp file nén ở đây: [AppHider.zip](https://github.com/pytago02/AppHider/raw/main/AppHider.zip)

Sau khi tải về, giải nén và chạy file `AppHider.exe`.
