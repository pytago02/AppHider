# AppHider

AppHider là một tiện ích nhỏ gọn gọn trên Windows giúp bạn nhanh chóng ẩn các ứng dụng đang chạy để bảo vệ sự riêng tư.

## Tính năng chính
- **Ẩn khi Alt+Tab**: Cửa sổ biến mất hoàn toàn khỏi màn hình và danh sách Alt+Tab.
- **Chỉ ẩn Taskbar**: Loại bỏ biểu tượng ở Taskbar nhưng vẫn giữ trong Alt+Tab.
- **Thao tác nhanh**: Hỗ trợ nút nổi (icon con mắt) ngay trên thanh tiêu đề của mọi ứng dụng để chuyển đổi chế độ nhanh chóng.
- **Giao diện hiện đại**: Hỗ trợ Dark/Light mode tự động tương thích với Windows 11.
- **Portable**: Tải về chạy ngay, không cần cài đặt.

## Tải về
Bạn có thể tải trực tiếp file nén ở đây: [AppHider.zip](AppHider.zip)

Sau khi tải về, giải nén và chạy file `AppHider.exe`.
